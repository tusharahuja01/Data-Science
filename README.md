# Data-Science

🧠 Loan Default Risk Prediction & California Housing Analysis Projects

Created By: Tushar Ahuja

Repository Overview:

This repository contains 10 end-to-end machine learning projects covering classification, regression, feature engineering, clustering, and model evaluation. Using real-world datasets from financial institutions and the California housing market, each project demonstrates a structured data science workflow with model development, evaluation, and interpretation.

📂 Project Overview
🔹 Project 1 – Exploratory Data Analysis (EDA) for Loan Default
Performs EDA on a financial institution's loan dataset to explore relationships between features and loan defaults. Lays the foundation for further modeling and decision-making.

🔹 Project 2 – Decision Tree Model for Loan Default Prediction
Builds and evaluates a basic Decision Tree Classifier. Focuses on feature importance, model behavior, and basic classification performance.

🔹 Project 3 – Model Evaluation Using Advanced Metrics
Evaluates the Decision Tree model using a comprehensive set of metrics including Accuracy, ROC-AUC, Precision, Recall, F1 Score, Gains Table, and the K-S statistic.

🔹 Project 4 – Enhancing Predictive Power via Feature Engineering
Applies mean imputation and mean encoding to handle missing and categorical data. Trains a new Decision Tree and compares performance with Project 3.

🔹 Project 5 – Logistic Regression for Loan Classification
Introduces Logistic Regression as a linear and interpretable classifier. Evaluates its effectiveness compared to the Decision Tree model and explores coefficient-based feature importance.

🔹 Project 6 – Predicting California Housing Prices with Linear Regression
Uses Linear Regression to model median housing prices across California. Involves EDA, feature analysis, diagnostics (residuals, Q-Q plots), and performance metrics like RMSE, MAE, and R².

🔹 Project 7 – Visualizing Housing Price Segments Using PCA, UMAP & t-SNE
Segments housing prices into Low, Medium, and High. Applies PCA, UMAP, and t-SNE to reveal data structure and cluster separability using the top regression features.

🔹 Project 8 – Customer Segmentation with Clustering Techniques
Applies K-Means, DBSCAN, and Agglomerative Clustering on marketing data. Uses PCA for 2D visualization and interprets cluster profiles to support business targeting strategies.

🔹 Project 9 – Comparing Ensemble Models for Loan Default Risk
Implements and compares four ensemble models — Random Forest, Gradient Boosting, XGBoost, and CatBoost — using extensive evaluation metrics and feature importance plots.

🔹 Project 10 – Regularized GLM Models and Ensemble Comparison
Builds Logistic Regression models with L1 (Lasso), L2 (Ridge), and ElasticNet regularization. Compares their performance against the ensemble models from Project 9 using Accuracy, ROC-AUC, and Lift Charts.
