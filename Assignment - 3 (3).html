Definitions and Model Performance Metrics¶

1. Accuracy:

  • Accuracy is the proportion of correct predictions (both true positives and true negatives) out of all predictions.

  • Formula: Accuracy= (TP+TN)/(TP+TN+FP+FN)

​

  • Where TP = True Positive, TN = True Negative, FP = False Positive, FN = False Negative.

2. ROC Curve (Receiver Operating Characteristic Curve):

  • The ROC curve (Receiver Operating Characteristic curve) plots the true positive rate (TPR) against the false positive rate (FPR) for different classification thresholds. It visually demonstrates the trade-off between sensitivity and specificity.

  • The AUC represents the area under the ROC curve, ranging from 0 to 1. A higher AUC indicates better model performance.

  • Formula:

    • TPR = (True Positives) / (True Positives + False Negatives)
    • FPR = (False Positives) / (False Positives + True Negatives)

3. Confusion Matrix:

  • A confusion matrix is a table that summarizes the performance of a classification algorithm. It provides a detailed count of correct and incorrect predictions categorized by their actual and predicted values. The confusion matrix helps in calculating other performance metrics, such as Precision, Recall, and F1 Score.

4. Gains Table:

  • A gains table evaluates the cumulative proportion of positive outcomes captured by the model as the decision threshold changes. It allows us to see the proportion of positives captured by the model, given a certain percentage of the population.

5. Kolmogorov-Smirnov (K-S) Statistic:

  • The Kolmogorov-Smirnov (K-S) statistic measures the maximum distance between the cumulative distribution functions (CDFs) of predicted probabilities for the positive and negative classes. The larger the K-S statistic, the better the model is at distinguishing between the two classes.

6. Precision:

  • Precision is the proportion of true positives among all the predicted positives. It is used to evaluate the accuracy of positive predictions.

  • Formula: Precision= (TP)/(TP+FP)

7. ​Recall (Sensitivity):

  • Recall measures the proportion of actual positives (defaults) that are correctly identified by the model.

  • Formula: Recall= (TP)/(TP+FN)

​8. F1 Score:

  • The F1 Score is the harmonic mean of Precision and Recall. It balances the trade-off between the two.

  • Formula: F1 = 2 × [ (Precision × Recall) / (Precision+Recall) ]

​

Why y_pred in Confusion Matrix?¶

  • The Confusion Matrix is a table used to evaluate the performance of a classification model. It compares true labels (y_test) with the predicted class labels (y_pred).
  • y_pred contains the final class predictions (like 0 or 1) after applying a threshold to the model's output probabilities.
  • Confusion Matrix calculations require discrete class labels (0 or 1), not probabilities. This is why y_pred is used.

Why Not test_pred?¶

  • test_pred typically contains predicted probabilities rather than class labels. For example:

    test_pred = [0.23, 0.45, 0.10, 0.85, 0.33, 0.76]

  • Since these are continuous values (between 0 and 1), they cannot be directly compared with y_test in a Confusion Matrix.

  • We need to convert probabilities into class labels by applying a threshold (e.g., 0.5):

    y_pred = [1 if prob > 0.5 else 0 for prob in test_pred]

    Result:

    y_pred = [0, 0, 0, 1, 0, 1]

  • Now, y_pred contains binary values (0 or 1), which are suitable for the Confusion Matrix.

# Importing necessary libraries
from sklearn.metrics import roc_curve, auc, precision_recall_curve, average_precision_score
import matplotlib.pyplot as plt

def evaluate_model(y_true, y_prob):
    """
    Evaluates the model using ROC-AUC and Precision-Recall curves.
    """
    # ROC Curve and AUC
    fpr, tpr, thresholds_roc = roc_curve(y_true, y_prob)
    roc_auc_value = auc(fpr, tpr)

    # Precision-Recall Curve
    precision, recall, thresholds_pr = precision_recall_curve(y_true, y_prob)
    avg_precision = average_precision_score(y_true, y_prob)

    # Displaying Metrics
    print('\nModel Evaluation Metrics:')
    print(f'ROC AUC Score: {roc_auc_value:.3f}')
    print(f'Average Precision Score: {avg_precision:.3f}')
    print('\n- ROC curve shows the trade-off between sensitivity (True Positive Rate) and fall-out (False Positive Rate).')
    print('- AUC indicates how well the model can distinguish between positive and negative classes.')
    print('- Precision-Recall curve focuses on positive class performance, suitable for imbalanced datasets.')

    # Plotting ROC Curve
    plt.figure(figsize=(12, 5))
    plt.subplot(1, 2, 1)
    plt.plot(fpr, tpr, color='darkorange', lw=2, label='ROC curve (AUC = %0.3f)' % roc_auc_value)
    plt.plot([0, 1], [0, 1], color='navy', lw=2, linestyle='--')
    plt.xlim([0.0, 1.0])
    plt.ylim([0.0, 1.05])
    plt.xlabel('False Positive Rate')
    plt.ylabel('True Positive Rate')
    plt.title('ROC Curve')
    plt.legend(loc='lower right')

    # Plotting Precision-Recall Curve
    plt.subplot(1, 2, 2)
    plt.plot(recall, precision, color='blue', lw=2, label='Precision-Recall Curve')
    plt.fill_between(recall, precision, step='post', alpha=0.2, color='blue')
    plt.xlabel('Recall')
    plt.ylabel('Precision')
    plt.title('Precision-Recall Curve')
    plt.legend(loc='lower left')
    plt.show()

Performance Metric: AUC-ROC¶

The AUC-ROC (Area Under the Receiver Operating Characteristic Curve) measures the effectiveness of a classification model:

  • AUC = 1: Implies the model perfectly distinguishes between classes.
  • AUC = 0.5: Represents a model that performs no better than random chance.
  • AUC < 0.5: Indicates the model is performing worse than random, suggesting it needs improvement.

Below code generates a Gains Table and Gains Chart to evaluate a classification model's performance by showing the cumulative percentage of actual vs. non-actual predictions in deciles, along with model lift and K-S statistic.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def gains_table(y_actual, y_pred_prob):
    # Creating a DataFrame to organize actual values and predicted probabilities
    df = pd.DataFrame({'actual': y_actual, 'pred_prob': y_pred_prob})
    
    # Sorting the DataFrame by predicted probabilities in descending order
    df = df.sort_values(by='pred_prob', ascending=False).reset_index(drop=True)
    
    # Creating deciles and handle duplicate bin edges
    df['decile'] = pd.qcut(df['pred_prob'], 10, labels=False, duplicates='drop')
    df['decile'] = 9 - df['decile']  # To make decile 0 as the top 10%
    
    # Calculating Gains Table
    gains = df.groupby('decile')['actual'].agg(['count', 'sum'])
    gains.columns = ['count', 'actual']
    gains['non_actual'] = gains['count'] - gains['actual']
    gains['cum_count'] = gains['count'].cumsum()
    gains['cum_actual'] = gains['actual'].cumsum()
    gains['cum_non_actual'] = gains['non_actual'].cumsum()
    gains['percent_cum_actual'] = (gains['cum_actual'] / gains['actual'].sum()).round(2)
    gains['percent_cum_non_actual'] = (gains['cum_non_actual'] / gains['non_actual'].sum()).round(2)
    gains['if_random'] = gains['actual'].sum() / 10
    gains['if_random'] = gains['if_random'].cumsum()
    gains['lift'] = (gains['cum_actual'] / gains['if_random']).round(2)
    gains['K_S'] = np.abs(gains['percent_cum_actual'] - gains['percent_cum_non_actual']) * 100
    gains['gain'] = (gains['cum_actual'] / gains['cum_count'] * 100).round(2)
    
    print("Gains Table:")
    print(gains)
    
    # Plot Gains Chart
    plt.figure(figsize=(10, 6))
    plt.plot(gains['percent_cum_actual'], label='Cumulative Actual', color='blue')
    plt.plot(gains['percent_cum_non_actual'], label='Cumulative Non-Actual', color='red')
    plt.xlabel('Decile')
    plt.ylabel('Cumulative Percentage')
    plt.title('Gains Chart')
    plt.legend()
    plt.grid(True)
    plt.show()
    
    return gains

# Call the function with actual values and predicted probabilities
gains = gains_table(y_test, test_proba[:, 1])

The Kolmogorov-Smirnov (K-S) Test is a statistical test used to compare the cumulative distribution functions of two samples. In the context of binary classification, it is used to evaluate the discriminatory power of a model by comparing the cumulative distribution of predicted probabilities for the positive and negative classes.

In this case, we'll calculate the K-S statistic using the predicted probabilities from the loan default prediction model. Here's how to do it:

In [881]:
import numpy as np
import pandas as pd
from sklearn.metrics import roc_curve
import matplotlib.pyplot as plt

def KS_Test(y_actual, y_pred_prob):
    # Create a DataFrame to organize actual values and predicted probabilities
    df_ks = pd.DataFrame({'actual': y_actual, 'pred_prob': y_pred_prob})
    df_ks = df_ks.sort_values(by='pred_prob', ascending=False).reset_index(drop=True)
    
    # Calculate cumulative distributions for positive and negative classes
    df_ks['cum_positive'] = (df_ks['actual'] == 1).cumsum() / (df_ks['actual'] == 1).sum()
    df_ks['cum_negative'] = (df_ks['actual'] == 0).cumsum() / (df_ks['actual'] == 0).sum()
    
    # Calculate K-S statistic
    df_ks['ks_stat'] = np.abs(df_ks['cum_positive'] - df_ks['cum_negative'])
    ks_value = df_ks['ks_stat'].max()
    ks_index = df_ks['ks_stat'].idxmax()
    
    print(f"Kolmogorov-Smirnov (K-S) Statistic: {ks_value:.3f}")
    
    # Plotting K-S curve
    plt.figure(figsize=(10, 6))
    plt.plot(df_ks['cum_positive'], label='Cumulative Positive', color='blue')
    plt.plot(df_ks['cum_negative'], label='Cumulative Negative', color='red')
    plt.axvline(x=ks_index, color='green', linestyle='--', label=f'K-S = {ks_value:.3f}')
    plt.xlabel('Sample Index')
    plt.ylabel('Cumulative Distribution')
    plt.title('Kolmogorov-Smirnov (K-S) Curve')
    plt.legend()
    plt.grid(True)
    plt.show()

# Call the function with the actual and predicted probabilities
